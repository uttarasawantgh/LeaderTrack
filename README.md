# LeaderTrack 🚀

> A personal leadership development companion for tracking screen-free evening reading routines, managing book progress, and capturing actionable wisdom.

![LeaderTrack Cover](./cover.png)

## 📌 Overview

**LeaderTrack** is a dark-mode web application engineered to structure and optimize personal leadership growth. It offers a distraction-free interface for tracking non-digital reading habits, calculating percentage-based progress across reading materials, and archiving chapter insights, quotes, and warnings into a persistent feed.

---

## ✨ Key Features

* **📖 Progress Tracking & Badging**: Monitor page completion and percentage progress with live SVG ring indicators. Distinct visual badges support special editions.
* **🌙 Evening Reading Routine**: Dedicated single-tap completion button designed specifically to encourage screen-free physical reading sessions.
* **⚡ Quick Log Form**:
  * Track time invested (15m, 30m, 45m, 60m).
  * Record page numbers read.
  * Capture key takeaways, chapter quotes, and personal cautions.
* **💡 Wisdom Feed**: A central activity stream that logs all completed reading entries, takeaways, and memorable quotes for easy review.
* **💾 Local State Persistence**: Automatically persists reading history, streaks, and card progress in the browser via `localStorage`.
